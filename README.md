# Release

自作ツールの配布用リポジトリです。実行ファイルは [Releases](https://github.com/hzukeyamaaa-code/release/releases) からダウンロードしてください。

## LiteExplorer

Tablacus Explorer に近い使い勝手の、軽量なタブ型ファイラーです（Windows 10 / 11、64bit）。

### 使い方

1. Releases から `LiteExplorer.exe` をダウンロードし、好きな場所に置きます。
2. ダブルクリックで起動します（.NET のインストールは不要です）。

初回起動時に「Windows によって PC が保護されました」と表示された場合は、［詳細情報］→［実行］を選んでください（署名のない exe のため表示されます）。

設定は `%APPDATA%\LiteExplorer\settings.json` に保存されます。別の PC へタブやお気に入りを引き継ぐ場合は、このファイルをコピーしてください。

## ClipboardPlus

クリップボードの履歴（文字・画像）とスクリーンショット、メモをまとめて扱う常駐ツールです（Windows 10 / 11、64bit）。

### 使い方

1. Releases から `ClipboardPlus.exe` をダウンロードし、好きな場所に置きます。
2. ダブルクリックで起動すると、タスクトレイに常駐します（.NET のインストールは不要です）。
3. `Win+Alt+V`（またはトレイアイコンのクリック）で画面を開き、項目を選んで Enter を押すと、元のウィンドウに貼り付けます。

### できること

- **すべて**: コピーした文字・画像の履歴（ピン留めしたもの以外は、文字 100 件・画像 200 件まで残します）
- **スクリーンショット**: `Win+Shift+S` などで撮った画像（Windows のスクリーンショットフォルダーを監視します）
- **メモ**: よく使う文章を登録しておけます（Ctrl+N か検索欄の右の［＋］で新規、Ctrl+S で保存）。編集中は画面の外をクリックしても閉じないので、ほかのウィンドウを見ながら書けます

画面の大きさは、辺や角をドラッグして変えられます（次に開くときも同じ大きさになります）。移動は、上部や下部の余白をドラッグします。

| 操作 | キー |
|---|---|
| タブの切り替え | Ctrl+1 ～ 3 |
| 検索 | Ctrl+F |
| 貼り付け / 削除 | Enter / Delete |
| 文字の履歴・メモの編集 | → |
| 閉じる | Esc |

ピン留め・メモへの追加・元ファイルの場所を開く、などは各項目のボタンからできます。終了はトレイアイコンの右クリック →［終了］です。

初回起動時に「Windows によって PC が保護されました」と表示された場合は、［詳細情報］→［実行］を選んでください。

データと設定は `%LOCALAPPDATA%\ClipboardPlus` に保存されます（トレイアイコンの右クリック →［データフォルダを開く］）。ホットキーや残す件数は、そのフォルダーの `settings.json`（`Hotkey`・`MaxHistoryItems`・`MaxScreenshotItems` など）を書き換えて、再起動すると変わります。

## LiteTaskManager

Windows のタスクマネージャーの軽量版です（Windows 10 / 11、64bit）。exe 1 つ（約 260KB）で動きます。

### 使い方

1. Releases から `LiteTaskManager.exe` をダウンロードし、好きな場所に置きます。
2. ダブルクリックで起動します（VC++ ランタイムなどのインストールは不要です）。

### できること

- **プロセス一覧**: 名前・PID・CPU・メモリ・スレッド数・ハンドル数を 1 秒ごとに更新します。列見出しのクリックで並べ替え（もう一度押すと逆順）
- **アプリごとのまとめ**: タスクマネージャーと同じく、同じアプリのプロセスを「Google Chrome (44)」のように 1 行にまとめて合計を出します。矢印のクリックやダブルクリックで展開・折りたたみ
- **CPU / メモリのグラフ**: 直近 60 秒の使用率。値の出し方はタスクマネージャーに合わせています。一覧の CPU・メモリは、使用量が大きいほど濃い青で表示します
- **フィルタ**: 名前・exe 名の一部か PID で絞り込みます
- **タスクの終了**: 選んだプロセスを終了します（確認あり）。まとめた行で行うと、そのアプリのプロセスをまとめて終了します

| 操作 | キー |
|---|---|
| フィルタへ移動 / クリア | Ctrl+F / Esc |
| 展開 / 折りたたみ | → / ← |
| タスクの終了 | Delete（右クリックメニューからも可） |

他のユーザーやシステムのプロセスを終了するには、右クリック →［管理者として実行］で起動してください。

初回起動時に「Windows によって PC が保護されました」と表示された場合は、［詳細情報］→［実行］を選んでください。

設定やデータは保存しません。
